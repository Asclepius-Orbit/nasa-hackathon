# Project sources and resources

This inventory supports the NASA Space Apps project submission. It records resources identifiable in the repository; the team must add any outside resources or AI tools used during development that are not recorded here. Listing a resource does not establish permission to redistribute it. Check the original licence and permissions, including for assets in any demo or submission outside this repository.

## NASA data and scientific references

The [anthropometry evidence inventory](anthropometry-sources.md) identifies the NASA publications, their authors, dates, specific pages, access links, limitations and reuse status, including NASA's Human Integration Design Handbook, NASA-STD-3000 and NASA-STD-3001, NTRS records 20110023150, 20090007782, 20090038743 and 19750006319, and Chang et al. (2016). The locally bundled [evidence corpus](../spine_monitor/mcp_server/src/spine_mcp_server/evidence_data/corpus.json) contains project-written summaries of the handbook and Thornton et al.; its links identify their sources. It is not an individual astronaut dataset. The NTRS API is a reference for connected preparation, not a runtime dependency.

The [exercise protocol](protocolo-ejercicio.md) cites the [Adafruit conductive rubber cord](https://www.adafruit.com/product/519) and the [conductive elastomer sensor study](https://doi.org/10.1002/admt.201700284) for material behaviour. Neither validates this experimental system.

## Hardware and protocols

- [Arduino Uno](https://docs.arduino.cc/hardware/uno-rev3/) and [Arduino AVR core](https://github.com/arduino/ArduinoCore-avr): wearable firmware, including Wire and EEPROM; [Arduino CLI](https://arduino.github.io/arduino-cli/) builds it.
- [Adafruit stretch sensor 519](https://www.adafruit.com/product/519), MPU-6050 inertial sensor and Muscle Sensor V3 EMG module: components described in the [firmware README](../firmware/README.md). The precise supplier and module documentation for the latter two are not established in the repository and need confirmation by the hardware team.
- [MQTT](https://mqtt.org/) and [Eclipse Mosquitto](https://mosquitto.org/): telemetry protocol and broker. [Model Context Protocol](https://modelcontextprotocol.io/) is used for agent tools. Project schemas are in [contracts](../spine_monitor/contracts/README.md).

## Software, models and tools

- [Python](https://www.python.org/), [uv](https://docs.astral.sh/uv/), [Node.js](https://nodejs.org/), [pnpm](https://pnpm.io/), [Docker](https://www.docker.com/) and [Debian](https://www.debian.org/) provide the development, runtime and container environment. Exact image tags and build instructions appear in [Compose](../app/docker-compose.yml) and the Dockerfiles.
- [Ollama](https://ollama.com/) serves the local language model. The default is [Qwen3.5 4B](https://ollama.com/library/qwen3.5); the [agent README](../spine_monitor/agent/README.md) also records evaluations of Qwen3.5 9B and Gemma 4. The model generates answers and reports from tool results; the fallback summary is deterministic. Model downloads and licences are separate from the repository.
- The [vendored skills inventory](../.claude/skills/THIRD_PARTY.md) identifies third-party code and text by upstream, revision and licence. The README also describes project-specific skills and Context7. Consult the individual notices before redistribution.
- The UI includes [Atkinson Hyperlegible Next](https://github.com/googlefonts/atkinson-hyperlegible-next) through Fontsource. The package and its licence are separate from this project's licence.

## AI and media disclosure

The running agent uses the local model described above to generate text. The repository documents Claude Code skills used for development and Context7 for documentation lookup; the team should disclose the specific tools, models and their actual uses in the submission, including any AI-generated code, text, images or audio. This inventory cannot establish every contributor’s use from the repository alone. The submission guide also requires visible identification of AI-generated images and video and disclosure for AI-generated audio, code and data. No separately tracked raster images, audio or video were identified in the repository; check presentation and demo assets separately.
